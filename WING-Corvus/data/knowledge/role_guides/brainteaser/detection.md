# 脑洞题特征库 (判断标准)

> 注入目标: 总指挥(commander) + 巡查器(strategy), 仅当需要判断是否脑洞题时
> 维护规则: 限字数 ≤4KB, 每次解题后复盘更新, 判断错误的案例也记录 (false positive/negative)

## 强特征 (≥1 条即高度怀疑为脑洞题)

1. **预期 flag 格式与题目描述不符** (如 README 放了一个前缀不匹配的 flag)
2. **附件包含明显误导性内容** (如 README 首行显眼位置的 flag 字符串)
3. **题目描述语义矛盾或异常** (如 'I gave you the key' 但 key 加了引号)
4. **标准工具/套路全部失败** (如 binwalk 无结果/steghide 无内容/标准 AES 解密出乱码)
5. **题目名称暗示'非常规'** (如 numerology/underhanded/chaos/ieee)

## 弱特征 (≥3 条可怀疑为脑洞题)

1. 附件包含非常见文件格式 (.avif/.bpf/自定义扩展名)
2. 无标准加密库/标准逆向工具能直接处理
3. 题目有多个独立附件且相互关联
4. 已知的 flag 字符串无法通过标准流程验证
5. 题目描述使用引号/反讽/隐喻等修辞

## 特征维护

每次解题后更新此文件:
- 判断为脑洞题且解出 → 记录确认的特征
- 判断为脑洞题但未解出 → 记录可能遗漏的特征
- 非脑洞题但判断为脑洞题 → 记录 false positive
