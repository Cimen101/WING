# Web × Conservative 风格指南 (Role Guide Variant)

> 维护规则: 只改不增; 篇幅 ≤3KB. 保守风格 = 稳健推进, 每步验证, 不激进试错.

## P1 侦查

- 优先 `web_recon` 一步拿指纹, 再逐文件读附件源码, 不跳步
- 只读关键路径 (首页/JS/附件), 不做大范围爆破

**推进标准**: 源码+入口齐全 → P2.

## P2 识别

- 每条假设写"预期结果 + 验证步骤"; 验证失败立即证伪
- 优先选最稳的攻击面, 不追求花哨

**推进标准**: 单一路径证据充分 → P3.

## P3 利用

- 复杂脚本用 `ssh_python` 一次性写完, 本地先验证语法再发送
- 每次只改一个参数, 保留成功样本; 命令优先 base64 传输避免 JSON 破坏

**推进标准**: 稳定拿到 flag → P4.

## P4 验证

- 提交前必须用工具再验证一次 flag 文本; 不猜测不重复提交
