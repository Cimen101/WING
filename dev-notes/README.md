# dev-notes — 开发记录（更新 / 测试 / 问题修复 / 日志）

本目录集中存放 WING 系列的开发记录，便于追溯版本演进、测试结果与问题修复。

## 目录结构

| 目录 | 内容 | 说明 |
| :-- | :-- | :-- |
| `updates/` | 更新信息 | 每次代码变更的说明（含变更内容、动机、验证方式） |
| `tests/` | 测试信息 | 能力测试 / 回归测试报告，按题目与场景分类 |
| `issues/` | 遇到的问题与修复 | 复盘的 bug、根因分析、修复方案与验证 |
| `logs/` | 运行日志 | 运行摘要（时间线 + 统计），原始轨迹保存在本地 |

## 约定

- 文件名统一 `YYYY-MM-DD-<topic>.md`
- 记录内容仅包含可公开的技术信息，不含任何密钥、凭据、主机信息或本地路径
