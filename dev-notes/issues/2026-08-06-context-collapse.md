# 问题与修复：hard 题长步骤格式坍塌（空输出）

- 日期：2026-08-06
- 影响：长上下文场景下 LLM 输出塌陷为全空，连续触发格式熔断

## 现象

hard 题运行时，尾部连续出现 `thought/action 全空` 的退化输出，被判定为"连续 5 次格式解析失败"熔断。且 tokens 累计可达 4M+，在解出前耗尽预算。

## 根因分析（基于完整轨迹统计）

- 对三路轨迹逐条分析确认：**全部格式错误均为"空输出"**，无字段缺失类格式错乱
- 上下文量化：系统提示词约 46K 字符（21 个工具 schema + 规则文本 + 知识注入）+ 10 轮滑动窗口（每轮 ≤8.5K 字符）≈ **131K 字符**
- 中文场景 token 换算（1 字符 ≈ 0.4-0.6 token）后逼近模型上下文窗口 → 输出塌陷
- 普通滑动窗口"整轮丢弃"会丢失关键事实，无法满足长 hard 题复盘需要

## 修复方案

1. **双端截断**（观察/助手侧）：重复行折叠 + 字符上限截断
2. **最小输出模式**：连续格式错误 ≥2 次时升级为极简输出指令
3. **智能上下文压缩**（核心）：
   - 实时打标保留级别（level0/1/2），关键证据永不压缩
   - 实时时间线保留关键事实串联线索
   - 动态异步预压缩 + 逼近上限一次性替换，不阻塞主循环
   - 首次空输出即触发压缩 + 提示词注入

## 验证

- 修复后同一 hard 题：84s 通过，12 步，零格式错误
- 54 个单元测试全绿（含空输出处理专项测试）
