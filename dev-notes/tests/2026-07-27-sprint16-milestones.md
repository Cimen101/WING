# 测试报告：Sprint 16 里程碑汇总（P11–P12）

- 日期：2026-07-27
- 版本：WING-Goose（雁阵）——旧版本
- 主题：自主基线 + Skill 库 + Planner 集成

## P11 — 自主解题基线 + Skill 库验证（6/6）

| 项 | 值 |
| :-- | :-- |
| 题目数量 | 6 道（纯风格 3 + 黑盒 3） |
| 结果 | 6/6（纯风格 3/3、黑盒 3/3） |
| 平均耗时 | 约 6 分钟 / 题 |
| 平均步数 | 10.2 步 / 题 |

对比 Sprint 15 P10 自主基线（3/6），本轮 6/6 全过，归因三方面：

1. **自主方法论落地**：结构化任务拆解显著降低无效探索；
2. **Skill 库注入生效**：套路知识直接可用，减少重复推导；
3. **max_steps 提升至 50**：放宽步数约束，留足容错空间。

## P12 — multi_agent Planner 集成（CHAP 协议）（6/6 持平）

| 项 | 值 |
| :-- | :-- |
| 结果 | 6/6（与 P11 持平） |
| 总耗时 | +8.6 min |
| 平均步数 | +6.6 步（10.2 → 16.8） |

multi_agent 模式引入 Planner 与 CHAP 协议后：

- **成功率**：保持 6/6 持平，说明多智能体协作不破坏自主解题能力；
- **代价**：总耗时增加 8.6 分钟、平均步数增加 6.6 步（16.8 步/题），协作协商与调度开销显著。

## 结论

- Skill 库 + 自主方法论 + 步数放宽，是成功率从 3/6 提升至 6/6 的关键组合。
- Planner / CHAP 协作协议在能力上「不破坏」、成本上「不划算」，后续迭代优先优化协作开销（精简协商轮次、减少冗余调度）。
