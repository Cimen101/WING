# 测试报告：4 hard + 1 附加题并发终极验证（WING-Corvus 2.0）

- 日期：2026-08-06
- 版本：WING-Corvus（渡鸦）——最新版本小版本更新
- 测试目的：知识库四层重构（见 `../updates/2026-08-06-knowledge-four-layer.md`）后的 hard 题压力回归

## 题目来源与信息

| 项 | 值 |
| :-- | :-- |
| 比赛来源 | 开源 CTF 仓库题目 |
| 题目 | todolist / cornflake / fast_is_need / artifact / ouroboros |
| 难度 | 4 hard + 1 附加题 |
| 运行方式 | 5 题并发，三路 swarm + 总指挥 |

## 结果汇总

| 题目 | 结果 | 说明 |
| :-- | :-- | :-- |
| todolist | 解出（仅一路成功） | 其余两路在解出后由兄弟 kill 终止 |
| cornflake | 失败（三路均失败） | 已写入 pitfalls |
| fast_is_need | 失败（三路均失败） | 已写入 pitfalls |
| artifact | 失败（三路均失败） | 已写入 pitfalls |
| ouroboros | 失败（三路均失败） | 已写入 pitfalls |

轨迹沉淀显示：**5 题中仅 todolist 一路成功，其余 4 题三路均失败**。

## 分析与处置

- 四题失败的共性模式（卡点阶段、失效方向）已逐题复盘并沉淀为 pitfalls 条目，供后续版本直接复用；
- todolist 的成功路径证明四层知识库检索与阶段化调度链路在 hard 题上仍可用；
- 失败集中在需要长链路状态维护 / 多工具链协作的题目上，与已知的上下文压缩边界相关（详见 `issues/2026-08-06-context-collapse.md` 的演进版本）；
- 结论：知识库重构未引入回归，hard 题短板根因在解题策略而非知识检索，转交后续调度优化排期。
