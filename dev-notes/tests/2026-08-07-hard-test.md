## 失败根因分析

### 1. Athena triplet-tweak（crypto）

- AES 密钥派生方式理解错误（采用了与题目实际派生流程不一致的方案），导致利用方向整体偏离；
- 修复密钥派生后进入重复提交死循环：同一错误提交反复重试，未触发回退与发散机制，耗尽步数。

### 2. SUCTF suctf_lock（reverse）

- 题目为 Inno Setup 打包的二进制；
- 环境中缺少 Inno Setup 解包工具，无法进入后续逆向阶段，属工具链缺口而非思路问题。

### 3. Athena tiny-ecc（crypto）

- 椭圆曲线参数处理中密钥派生错误，私钥恢复失败；
- 与 triplet-tweak 的失败模式同源：对"密钥派生"类步骤缺少确定性验证环节。

## 处置

- triplet-tweak / tiny-ecc：密钥派生类步骤追加确定性中间校验，重复提交触发卡住检测；排期实现；
- suctf_lock：补充 Inno Setup 解包工具进内置工具链；
- 失败模式均已记录 pitfalls，供知识库自动沉淀。
