# 更新记录：智能上下文压缩 + 合规联网搜索 + LWE 解码工具（Sprint 36.4.x）

- 日期：2026-08-06
- 版本：WING-Corvus（主线）

## 变更内容

### 1. 智能上下文压缩（异步事件驱动 + 动态压缩 + 实时时间线）

**背景**：hard 题长步骤场景下，每步 LLM 调用上下文 = 系统提示词（约 46K 字符）+ 10 轮滑动窗口（每轮 ≤8.5K 字符）≈ 131K 字符，中文场景换算后逼近模型上下文窗口，导致 LLM 输出塌陷为全空（thought/action 全空），连续触发格式熔断。

**实现**（`memory/compressor.py` + `memory/short_term.py` + `agent/react.py`）：

- 每轮交互**实时打标**保留级别：
  - `level0` 全部保留：关键证据（协议/flag/验证成功标记）、关键工具成功结果、战略指导轮、最近 3 轮
  - `level1` 部分保留：普通成功工具轮（thought 头部 + action + observation 首尾）
  - `level2` 动态压缩：错误轮 / 纯观察轮（压缩为一行摘要）
- **实时时间线**：每步提取关键事实/关键操作，串联注入上下文；压缩后线索不丢
- **异步事件驱动**：后台线程持续对 level1/2 轮预压缩（纯文本处理，不写共享内存），主循环不被阻塞
- **逼近上限才替换**：上下文字符估算超过硬上限时，主线程一次性应用压缩（纯内存操作，毫秒级）
- **首次格式坍塌即压缩**：检测到空输出时立即收缩上下文并注入提示词，阻断坍塌扩散

### 2. 合规联网搜索（反 writeup 护栏）

- `web_search` 工具泛化为通用技术查阅（非仅 OSINT），任何题型可查算法/库/协议等通用原理
- 工具级护栏：查询含 writeup / solution / 题解等关键词直接拒绝
- Prompt 级规则（`COMPLIANCE_SEARCH_RULES`）：禁止搜索题目名 / writeup / 出题人题解，只允许搜索通用技术原理

### 3. LWE 解码工具（`tools/lwe_tool.py`）

- 已知误差向量绝对值 `|e|`（符号未知）时，用按幅度缩放的嵌入格 + LLL 恢复私钥 `s`
- 支持两种用法：内联参数 / 文件路径（大矩阵场景）
- **数学自动验证**：求解后校验 `A·s+e ≡ b (mod q)` 逐分量成立才返回成功，杜绝误报
