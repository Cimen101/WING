# 更新记录：role_guides 角色指南重构——两级角色分离

- 日期：2026-08-08
- 版本：WING-Corvus（渡鸦）——最新版本小版本更新

## 背景

原 role_guides 采用"每题型 1 个"的角色指南：每种题型一份文档，同时承载总指挥分工经验与解题器执行策略，运行中暴露出两类问题：

1. **职责混淆 / 注入层级错误**：题型级分工经验（派谁侦查、谁攻坚、如何配合）被注入到解题器（agent）上下文，而解题器真正需要的是本阶段、本风格的具体执行策略；总指挥侧反而拿不到分工经验。
2. **粒度不足**：单文档无法覆盖"题型 × 阶段 × 风格"的组合，风格变体（conservative / aggressive / innovative）不完整，部分风格缺少专属策略。

另有一个流程性问题：知识沉淀"只改不增"，运行中新产生的有效策略只能覆盖旧条目，阻碍自学习。

## 变更内容

重构为两级角色分离：

### 1. 顶层 `{type}.md`（7 题型）

- 每题型 1 份总指挥分工经验，共 7 类题型
- 注入目标：commander / strategy 层（总指挥与战略规划）
- 内容：题型特征识别、分工建议、协作要点、常见陷阱与止损时机

### 2. `agents/{type}-{phase}-{style}.md`（84 个）

- 解题器执行策略：7 题型 × 4 阶段 × 3 风格 = 84 份
- 注入目标：tactic 层（解题器执行策略）
- 内容：按阶段（侦查 / 分析 / 突破 / 收尾）与风格（conservative / aggressive / innovative）拆分的最小执行策略单元

### 3. `brainteaser/`（脑洞题专项）

- `detection.md`：脑洞题特征库（强特征 / 弱特征），用于解题前置的脑洞题识别
- `general.md`：通用策略 12 模板（固定/近固定模板，脑洞题无法定位唯一题型时兜底使用）
- `cases/`：历史脑洞题案例（沉淀可复用的破题模式）

## 修复的问题

| 问题 | 修复 |
| :-- | :-- |
| 注入层级错误（题型级分工经验误注入 agent） | 分工经验改注入 commander/strategy 层，执行策略注入 tactic 层 |
| 风格变体不完整 | 补齐 3 风格 × 4 阶段全组合（84 份） |
| 只改不增，阻碍自学习 | 运行后可追加新风格/新阶段条目，按累计方式沉淀而非覆盖 |

## 验证

- 注入目标与文档类型匹配校验通过：commander/strategy 仅接收顶层文档，tactic 仅接收 agents 文档
- 脑洞题特征库与 12 模板在后续批次复用，见 `tests/2026-08-08-gctf-hard-reverse.md` 与 `updates/2026-08-11-brainteaser-capability.md`
