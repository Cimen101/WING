# 更新记录：脑洞题能力升级方案（Sprint 37）

- 日期：2026-08-11
- 版本：WING-Corvus（渡鸦）——最新版本小版本更新

## 背景

前置 3 道脑洞题（rev-ieee / crypto-underhanded / crypto-numerology）全部失败（0/3）。对轨迹复盘后暴露 7 个系统性问题，本方案针对性地补齐脑洞题识别、自学习与异常恢复能力。

## 暴露的 7 个问题

| # | 问题 | 影响 |
| :-- | :-- | :-- |
| 1 | API 中途耗尽无恢复 | 长轨迹运行中配额耗尽，任务直接中断且无恢复机制 |
| 2 | AESSidechannel 工具路径断裂 | 侧信道工具引用路径失效，调用即报错 |
| 3 | role_guides 注入层级错误 | 题型级分工经验误注入 agent，总指挥侧缺失（已修复，见 `updates/2026-08-08-role-guides-restructure.md`） |
| 4 | 无脑洞题判断机制 | 解题前无法识别"脑洞题"，沿用常规流程必然超时 |
| 5 | 无自学习闭环 | 解出 / 失败后特征与策略不沉淀，同类题重复踩坑 |
| 6 | 巡查器 L2 LLM 异常无恢复 | 二级巡查调用异常后无降级路径，巡查链断裂 |
| 7 | steps 回传为 0 | 非胜出路 steps 统计回传为 0，汇总数据失真 |

## 升级方案

### 1. API 配额监控 / 恢复

- 运行前与运行中监控配额余量，接近阈值时告警
- 中途耗尽时保留已解证据并支持断点恢复（重新领题续跑）

### 2. 脑洞题判断机制

- 强特征：题目名 / 描述明显玩梗、机制跳脱常规（如"题目即提示"类）
- 弱特征：常规流程多步无进展、flag 格式异常、题目附件与描述不符
- 命中弱特征时由 LLM 做二次判断，确认后切换脑洞题解题路径

### 3. 自学习闭环

- 解题成功后自动更新脑洞题特征库（detection.md）、通用策略（general.md 模板）与案例（cases/）
- 失败时记录失败模式，供后续批次参考
- 与 curator 沉淀管线联动，见 `updates/2026-08-12-knowledge-accumulation.md`

### 4. 巡查器 L2 降级

- L2 巡查 LLM 异常时降级为 L1 规则级检查，不阻断主流程

### 5. 其他修复

- AESSidechannel 工具路径修正，并纳入工具自检清单
- steps 回传统计修正

## 验证

- 以 3 道脑洞题（rev-ieee / crypto-underhanded / crypto-numerology）作为回归集
- 自学习闭环验证：解题后检查特征库 / 策略 / 案例是否自动更新
